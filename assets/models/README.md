# 3D-модели серий

Страница `series.html` ищет файлы `.glb` в этой папке. Пока модель загружается,
в окне показывается кольцевой спиннер на фоновой сетке; при отсутствии файла
остаётся только фоновая сетка.

Ожидаемые имена:

| Серия | Файл |
| --- | --- |
| Formula 1 | `f1-2026.glb` |
| GT3 | `gt3-2026.glb` |
| WEC | `wec-hypercar.glb` |
| WRC | `wrc-rally1.glb` |

Требования к модели: формат glTF Binary (`.glb`), начало координат — центр машины,
масштаб в метрах, материал PBR. После добавления файла ничего менять в коде не нужно:
`<model-viewer>` подхватит его автоматически, включит автовращение и управление камерой.
