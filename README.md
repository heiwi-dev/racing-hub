# Racing Hub

Мультикатегорийный сайт-портфолио об автоспорте: Формула-1, GT3, WEC/Hypercar
и WRC. Один хаб, четыре дисциплины, записи с фильтрами и модальными окнами.

Демо-контент: гонки, результаты и цитаты вымышлены — проект сделан как портфолио.

## Запуск

Сайт статический, без сборки и зависимостей:

- откройте `index.html` двойным щелчком — всё работает с диска;
- или поднимите локальный сервер: `python -m http.server 8000` и перейдите на
  `http://127.0.0.1:8000`.

## Структура

```
index.html      хаб: hero, сетка серий, манифест, контакты
series.html     шаблон серии: баннер, факты, вкладки сезонов, календарь этапов, материалы, модальное окно
css/style.css   дизайн-токены, сетки, анимации, адаптив, светлая тема
js/data.js      контент: серии, трассы, календари 2024–2026, записи, моменты, результаты
js/app.js       тема, каталог серий, reveal-анимации, меню
js/series.js    рендер серии, вкладки сезонов, карточки этапов, модальное окно
assets/         favicon.svg и racinghub/ — оригинальные логотипы серий
```

## Как это работает

- **Одна страница на все серии:** `series.html?s=f1|gt3|wec|wrc`.
  Контент подставляется из `js/data.js`.
- **Сезоны в URL:** `series.html?s=f1&season=2025` — ссылку можно скопировать,
  активная вкладка восстановится. По умолчанию открывается 2026 год.
- **Календарь этапов:** у каждой серии есть `races` для 2026, 2025 и 2024.
  Переключение вкладок мгновенно перерисовывает карточки без перезагрузки.
- **Обложки трасс:** `data.circuits` хранит SVG-контур каждого автодрома.
  На карточке он рисуется неоновой линией в акцентном цвете серии, с сеткой,
  свечением и точкой старт/финиш. Клик по карточке открывает разбор этапа:
  трассу, таймлайн моментов, результаты и кнопку плеера.
- **Акцент серии:** задаётся переменной `--accent` на `<html>`, поэтому
  перекрашивается весь интерфейс, включая бейджи и графику.
- **Тема** хранится в `localStorage`: `rh-theme`.
- **Модальное окно** построено на нативном `<dialog>`: Esc, фокус-трап и
  возврат фокуса работают из коробки.

## Как добавить этап в календарь

Добавьте объект в `races` нужного сезона внутри серии в `js/data.js`:

```js
{
  gp: 'Гран-при Италии',       // название этапа
  circuit: 'monza',            // ключ из data.circuits
  date: '2026-09-06',          // дата гонки
  winner: 'Шарль Леклер',      // победитель (для разбора)
  team: 'Ferrari'
}
```

Если нужного автодрома нет в `circuits`, добавьте его туда: `name`, `city`,
`country`, `length`, `laps`, `signature` и SVG `path` в системе 240×140.
Номер этапа, счётчики вкладок и сетка обновятся автоматически.

## Как добавить запись

Добавьте объект в `entries` нужной серии в `js/data.js`:

```js
{
  id: 'f1-new-2026',          // уникальный id
  type: 'race',               // race | quali | tech | highlight
  season: 2026,
  date: '2026-10-01',
  readTime: 6,
  title: 'Заголовок',
  summary: 'Короткое описание для карточки и модального окна.',
  moments: [{ time: 'Круг 1', title: 'Событие', text: 'Что произошло.' }],
  results: [{ pos: 1, name: 'Пилот', team: 'Команда', gap: '1:23:45.678' }],
  stats: [{ value: '50/50', label: 'подпись' }]   // опционально, для техноанализа
}
```

Сезоны и счётчики во вкладках, а также подписи «Этапов» и «Команды» в фактах пересчитываются автоматически. Поле `pole` у этапа показывает поул-позицию, а `status: 'upcoming'` скрывает результаты ещё не состоявшейся гонки.

## Доступность и адаптив

- Клавиатурная навигация, видимый фокус, `aria`-атрибуты, skip-link.
- `prefers-reduced-motion` отключает анимации и reveal-эффекты.
- Сетки: 3 → 2 → 1 колонка, мобильное меню, тач-цели от 40 px.
